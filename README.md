**Vice Tracker** — an offline, open-source GTA 6 trophy guide and tracker for PlayStation 5: all 55 official trophies with a guide in our own words (with cited sources), a checklist saved in the browser with export/import, filters by kind, a spoiler setting for story trophies, a roadmap to the platinum, and every missable trophy flagged.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. No build step, no network requests at runtime — the guide is plain static files under `app/`.
